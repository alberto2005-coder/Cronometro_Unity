## Versión en Español

Este es un proyecto de cronómetro intuitivo y visualmente atractivo creado con Unity. Ideal para aplicaciones de seguimiento de tiempo o como base para juegos que requieran mecánicas de temporizador.

### Características
- ⏱️ **Cronometraje preciso:** Seguimiento de minutos, segundos y milisegundos.
- 🏁 **Sistema de Vueltas:** Registra múltiples vueltas con un solo clic.
- 🎨 **Interfaz Dinámica:** Cambios de color automáticos para identificar la vuelta más rápida (Lila) y la más lenta (Rojo).
- 🛠️ **Fácil Configuración:** Personaliza colores, grosores de borde y fuentes directamente desde el Inspector de Unity.
- 📱 **Responsivo:** Diseñado para funcionar en diversas resoluciones de pantalla.

### Estructura del Proyecto
- `Assets/Scripts/`: Contiene la lógica principal (`Cronometro.cs`) y controladores de UI.
- `Assets/TextMesh Pro/`: Recursos de fuentes para una tipografía nítida.
- `Assets/art/`: Sprites y recursos visuales para los botones y fondos.

### Requisitos
- Unity 2021.3 LTS o superior (recomendado).
- Paquete TMPro (incluido en la mayoría de versiones modernas de Unity).
- Universal Render Pipeline (URP).

### Instalación
1. Clona este repositorio.
2. Abre la carpeta `cronómetro` con Unity Hub.
3. Asegúrate de tener instalados los paquetes de TextMeshPro si el editor lo solicita.

## English Version

This is an intuitive and visually appealing stopwatch project created with Unity. Ideal for time-tracking applications or as a base for games requiring timer mechanics.

### Features
- ⏱️ **Precise Timing:** Track minutes, seconds, and milliseconds.
- 🏁 **Lap System:** Record multiple laps with a single click.
- 🎨 **Dynamic UI:** Automatic color changes to identify the fastest (Lilac) and slowest (Red) laps.
- 🛠️ **Easy Configuration:** Customize colors, outline thickness, and fonts directly from the Unity Inspector.
- 📱 **Responsive:** Designed to work across various screen resolutions.

### Project Structure
- `Assets/Scripts/`: Contains the core logic (`Cronometro.cs`) and UI controllers.
- `Assets/TextMesh Pro/`: Font assets for crisp typography.
- `Assets/art/`: Sprites and visual assets for buttons and backgrounds.

### Requirements
- Unity 2021.3 LTS or higher (recommended).
- TMPro package (included in most modern Unity versions).
- Universal Render Pipeline (URP).

### Installation
1. Clone this repository.
2. Open the `cronómetro` folder with Unity Hub.
3. Ensure TextMeshPro packages are installed if prompted by the editor.
